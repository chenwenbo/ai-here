## 已验证

- 安装脚本编译、签名完成；`doctor --json` 返回 1.4.0，并包含“AI Here · 带上下文启动”服务。
- 原生面板从 Finder 选中文件获取目录和参考路径；实际点击移除、打开文件选择器添加第二份中文材料，列表正确更新。
- 填写多行中文任务；选择明确的交接记录后显示来源、时间、状态、记录 ID 和正文预览。
- “继续上次会话”遇到新任务或材料时明确拒绝；返回面板后草稿与参考材料保留。
- 用测试目录及测试交接启动 Claude 桌面入口。UI 显示复制提示，实际生成的私有 `request.json` 包含正确目录、工具、指定交接 ID 和原始多行文本。剪贴板与 `prompt.md` 字节一致，文件权限为 0600。此轮最后的启动任务没有参考路径；两份材料的界面添加与后端传递分别由 UI 验收和自动化测试覆盖。
- 自动化覆盖相对/中文/特殊字符路径、指定记录快照、无隐式接续、失效记录、读取错误、提示字节预算、缓存权限/符号链接、失败恢复、终端单参数传递、桌面复制顺序和 WorkBuddy 短深链。
- 原生 helper 回归测试执行编译后的真实函数，校验目录/普通文件，以及 `/private/tmp` 与 `/tmp` 的一致比较。

## 网页预览

`python3 scripts/preview-ui.py` 在 127.0.0.1:8787 提供独立静态预览。已用浏览器实际验证材料添加、交接选择、桌面目标切换、启动结果预览、重置、圆角/字号调节。650px 窗口自动变为单列，没有横向溢出。

HTML/CSS/JS 源码变化触发刷新，草稿和样式调节保存在浏览器本地。预览使用示例目录与记录，不读取真实项目、不调用启动器，也不自动修改原生界面。

## 验收边界

这里证明了启动请求及提示传递，不代表 Agent 已读取文件、完成任务或写回结果。CLI 自动化使用受控测试命令验证参数；未在本轮发送真实模型任务。WorkBuddy 客户端先前的会话创建超时仍是独立待验证问题。
